# 02.11.2026 — Первый внешний юзер: не запускается установщик (раскладка mods\)

## Симптом (лог от товарища юзера)
- Машина: `D:\games\Terminator - Dark Fate - Defiance\` (стандартное имя GOG).
- `INSTALL_v2.0.0_GOG19.bat` → XML-фаза → `Game root not found (no basis.pak): D:\games`.
- Движок-фаза не запускалась, `logic.dll` НЕ тронут (защита сработала штатно).

## Диагноз
- Скрипт лежал **прямо в `mods\`**: `mods\PREPARE_XML_v2.0.0_GOG19.ps1`.
  Товарищ разложил корень архива в mods, а не папку `FagotM2_2.0.0_1.0.9_GOG\`.
- PREPARE считает GameRoot = 2 уровня вверх от скрипта → `D:\games` → нет
  `basis.pak` → честный стоп. Ожидаемая раскладка:
  `mods\<папка мода>\*.bat|*.ps1` (внутри архива папка уже правильная).

## Отданное юзеру решение (руками, без перекачки)
1. В `mods\` создать папку `FagotM2_2.0.0_1.0.9_GOG`.
2. Перенести ВСЁ из `mods\` внутрь неё (bat, ps1, basis, dlc, localization, mod.json).
3. Запускать bat ИЗНУТРИ этой папки; после [DONE] — меню MODS → включить пакет.

## Харденинг (внесён в PREPARE_XML_v2.0.0_GOG19.ps1)
- GameRoot теперь ищется walk-up до 4 уровней (у INSTALL_LOGIC общий
  Find-Bin уже умел ходить вверх — теперь PREPARE не слабее).
- Если script прямо в `mods\` (родительская папка = mods) → понятная ошибка
  с правильной раскладкой, exit 5, ничего не пишется.
