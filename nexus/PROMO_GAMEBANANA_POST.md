## EN

This fan mod [b]replaces the vanilla Javelin ATGM with the Fagot-M2 multirole ATGM suite[/b]: EMP, Neural Breach («Schizo», allied autonomous unit) and Cyber Hack («Takeover», direct player control) — plus the stock rocket, for four selectable fire modes total in one launcher.

[b]Modes:[/b] 🚀 Stock ATGM · 🔵 EMP (~45 s suspension) · 🟡 Neural Breach (ally-colored autonomous team) · 🟢 Cyber Hack (player-controlled team)

Targets affected: infantry ATGM units across campaign, Skirmish and DLCs (We Are Legion / Uprising). The vanilla Javelin is replaced everywhere the launcher is available.

[b]Status: working beta[/b] — bugs exist, but the mod is functional. Known issue: some Takeover-captured units (robots/spiders) keep a residual AI controller; a diagnostic trace build (REV1.9.4 TRACE V2) logs captured targets to bin\FagotM2_debug.log to help fix it. No global AI hooks. Requires game build 1.08.1173 (the installer verifies logic.dll SHA256 automatically and refuses mismatched builds; verified backup + one-command rollback are built in).

[b]Install (Windows):[/b] close the game → copy the mod folder to …\Terminator Dark Fate - Defiance\mods\<mod folder>\ → run INSTALL_FINAL.bat → in-game MODS menu: enable the package. Rollback: RESTORE_REV1.9.1_STABLE.bat.

[b]Where to get it:[/b] Nexus Mods page: https://www.nexusmods.com/terminatordarkfatedefiance/mods/105 — main distribution is on Nexus (free account required); source code & docs: https://github.com/Aleksandr-RY/fagot-m2-defiance
