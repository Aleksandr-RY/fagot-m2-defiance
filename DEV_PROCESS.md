# DEV_PROCESS — регламент разработки Fagot-M2

Родился из инцидента 28.10.2026 (0xc000007b, см. `journal/2026-10-28_badimage_machine_byte.md`).

## Сборка

1. **Бинарь руками не правится.** Все изменения байт — только через генераторы
   `tools/*.ps1`, лежащие в репо. Генератор = исходник патча.
2. **LoadLibraryEx-тест обязателен.** Ни один мастер не считается годным и не
   отдаётся юзеру, пока не прошёл локальный тест загрузчика
   (`LoadLibraryEx` + `DONT_RESOLVE_DLL_REFERENCES`). Ошибка 193
   (ERROR_BAD_EXE_FORMAT / 0xc000007b) = брак, игра для «проверки» не запускается.
3. **Байт-дифф к каждой сборке.** Полный дифф сток→мастер; число регионов
   изменений = числу заявленных окон. Лишний или неожиданный регион = брак сборки.
4. **SHA-реестр.** Каждый артефакт (сток / dry / мастер / битый мастер) имеет
   SHA256 в `BUILD_INFO.json`. Установщик сверяет SHA до и после патча,
   ставит через staging-копию.

## Версии

5. Одна ревизия движка = один каноничный мастер на пару (версия игры × ревизия).
   Золотые сборки (1.08-мастер) не трогаются — изменения только новой ревизией.
6. Изменение байт-таблиц = коммит в репо в тот же день (генератор + окна + SHA).

## Тестирование

7. **Лестница тестов:** загрузчик (п.2) → репетиция установщика локально на
   ВСЕХ ветках входа (сток, ремонт; результат побайтно = мастеру) → юзер в игре
   (запуск + 4 режима + `bin\FagotM2_debug.log`) → и только потом зипы/релиз.
8. Релиз-ассеты обновляются только после зелёного игрового теста.

## Журналирование

9. **Записывается всё:** каждый запуск игры, каждый краш (код, диалог, файл),
   каждая гипотеза с вердиктом (подтверждена/опровергнута), виновник, фикс.
   Формат — incident-репорт в `journal/` в тот же день. Пустых гипотез в записях
   не оставлять: у каждой — чем проверяли и чем кончилось.

## Скрипты (PS 5.1)

10. Без `??` и тернарников (`?:`) — только `if/else`.
11. Хвостовые запятые в `@(...)` и запятые-в-выражениях (`@($a,$b-$c)`) — под запретом;
    сначала вычислить в переменную.
12. `.ps1` с кириллицей — только UTF-8 **с BOM**; вывод консоли — ASCII.
13. Пути с пробелами — через `-LiteralPath`.
14. **Пароль PAK игры никогда не попадает в публичные файлы** (репо, архивы,
    Nexus) — только плейсхолдер.

## Nexus

15. В Nexus-архиве запрещены: .bat/.ps1/.exe, вложенные архивы, пароль PAK,
    дубли DLL, .pdb, бэкапы. Обход через переименование в .txt — запрещён.
16. Скрипты-установщики живут только на GitHub; README_CLEAN связывает архив
    с репо. Языки описания: РУС → 中文 → EN. Честная бета, known issues не прятать.
