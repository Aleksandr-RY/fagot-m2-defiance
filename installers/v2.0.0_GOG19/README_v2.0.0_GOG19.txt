ЧТО ЭТО
-------
Перенос мода «Fagot-M2» на GOG 1.9 (версия мода 2.0.0). Две части:

1) XML-оверрайды — профили трёх боеголовок («ЭМИ» / «Шизофреник» /
   «Перехват», радиус 30), RU-названия, DLC (Legion/Resistance/Canada),
   predefined-сейв. Установщик сам извлекает СТОКОВЫЕ XML из PAK-ов
   игры и кладёт пропатченные копии ТОЛЬКО в эту мод-папку.
   Сами PAK-и игры не изменяются. Нужен установленный 7-Zip.

2) Движок — байт-патч bin\logic.dll НА МЕСТЕ (вариант Б, без готового DLL):
   - 8 окон правок внутри стока (65 байт): шапка PE (секция .fgt5,
     SizeOfImage) + 4 CALL-трамплина;
   - надстройка хвоста 4336 B (вся страница cave: диспетчер режимов,
     debug-лог, RESET-блок и REV1.9.2-guard);
   - после патча файл побайтно равен проверенному мастеру REV1.9.2
     (9 257 984 B), SHA256 34e2abd2… — сверяется ДО подмены.
   REV1.9.2-guard закрывает вылет Шизофреника/Перехвата, найденный
   на v1.08.1173 (там проверен: кампания пройдена без крашей).

КАК СТАВИТЬ
-----------
1. Закрыть игру.
2. Запустить INSTALL_v2.0.0_GOG19.bat из этой папки (папка должна
   лежать в mods\ игры — корень находится автоматически):
   [1/2] PREPARE_XML_v2.0.0_GOG19.ps1 — XML-фаза (нужен 7-Zip);
   [2/2] INSTALL_LOGIC_v2.0.0_GOG19.ps1 — байт-патч logic.dll.
   Повторный запуск безвреден — обе фазы идемпотентны.
3. Проверить вывод: [PASS]/[OK] по всем строкам, в конце [DONE].
4. В меню MODS включить «Fagot-M2 FINAL 4 Modes v2.0.0».

ОТКАТ
-----
- RESTORE_GOG19.bat — вернуть logic.dll из бэкапа;
- XML-оверрайды живут только в этой папке: выключил мод в меню MODS
  (или удалил папку) — стоковые данные снова в силе.

ТЕСТ НА 1.9
-----------
1. «ЭМИ» — глушит технику, не крашит.
2. «Шизофреник» — включая убойные попадания по своим/по врагам:
   падений быть не должно. Побочный эффект: СВОИ юниты в пятне
   разрыва перекрашиваются в жёлтый — штатная логика «промывки
   мозгов», оставлена как фича.
3. «Перехват» — в т.ч. по вражеским ракетам (Fnd_missile_squad).
4. Радиус всех трёх: 30.
При вылете: RESTORE_GOG19.bat + свежий bin\FagotM2_debug.log.

Замечание: иконки wpn_mg_atgm.dds в PAK-ах 1.9 нет (как и на 1.08) —
игра подставит стандартную; на работу мода не влияет.
